# 确认后任务显示验证

2026-10-26：线上日志发现 POST /api/radar/tasks 的 400 与 502 失败请求。该类请求未成功创建任务；原错误位于长弹窗顶部，用户在底部确认时可能看不到。

修复：错误固定显示在确认按钮旁；失败保留草案。保存成功后先用服务端返回任务更新列表和详情，再刷新其他信息；旧轮询不能覆盖保存结果；提醒或配置刷新失败不会阻止任务列表更新，且明确区分“任务未保存”和“任务已保存、部分状态刷新失败”。新任务保存后清空旧的搜索与筛选条件。创建示例以A股扶摇链路为主。

浏览器回归通过：模拟400失败，桌面与390px手机均能看到确认旁错误；输入草案保留。重试成功后，模拟提醒接口503及旧轮询延迟返回空列表，任务详情与总览仍显示新任务，搜索／筛选已清空。无浏览器脚本错误。报告与截图保留于本地outputs/save-flow-browser-validation.json及save-error-*.png。

后端回归：扶摇A股任务保存后，行情429只将执行记为unknown/degraded，任务仍列出且不生成提醒；非法来源匹配仍返回400。当前修复不绕过标的或条件校验。
